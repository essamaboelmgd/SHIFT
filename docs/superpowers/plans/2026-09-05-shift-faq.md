# SHIFT FAQ Editorial Accordion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a responsive, accessible, line-based FAQ accordion after Why SHIFT without modifying existing section implementations.

**Architecture:** A dedicated `FaqSection.tsx` owns typed FAQ data and one-open-at-a-time state. A source contract test protects copy, chapter configurability, accessibility attributes, integration order, and isolated CSS selectors; browser verification covers actual accordion behavior and responsive layout.

**Tech Stack:** React 18, TypeScript 5.6, CSS, Vite 5, Node built-in test runner.

## Global Constraints

- Use `chapterNumber?: string` with default value `07`.
- Use Arabic wording: `مدة تنفيذ واضحة`, `نطاق واضح`, and `طريقة عمل أو منطق خاص`.
- Use no cards, shadows, item backgrounds, parallax, or entrance reveals.
- Keep only one FAQ open, with the first open by default.
- Use proper buttons, `aria-expanded`, `aria-controls`, stable ids, and visible focus.
- Animate answers without fixed `max-height`.
- Do not modify previous section markup or styling.
- Re-read shared files immediately before minimal integration patches because other agents are working concurrently.
